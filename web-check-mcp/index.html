What it is

Agentic wrapper over web-check: 31 OSINT checks exposed as MCP tools and CLI, with caching, rate limiting and Docker support.

Агентская обёртка над web-check: 31 OSINT-проверка как MCP-тулзы и CLI, с кэшированием, rate limiting и Docker-поддержкой.

Install

docker run -d --name web-check -p 3000:3000 lissy93/web-check

Python. Standard library first: the tool reads the data you point it at and sends nothing anywhere.

Where it fits

Use it when the output has to hold up to parsing or review, not when the voice is the point. Every rule can produce a false positive, so treat the findings as candidates for a rewrite.
