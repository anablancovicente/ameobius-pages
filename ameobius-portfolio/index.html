What it is

Portfolio site: every project in one place — MCP servers, browser and CDP pipelines, audio and music-AI wrappers, quality gates. RU/EN/ZH, published on GitLab Pages with a Vercel mirror.

Портфолио-лендинг: все проекты в одном месте — MCP-серверы, браузерные и CDP-конвейеры, обёртки аудио и music-AI, контроль качества. Три языка интерфейса, деплой на GitLab Pages и зеркало на Vercel.

Install

git clone https://gitlab.com/ameobius-ai/ameobius-ai.gitlab.io && cd ameobius-ai.gitlab.io

Web. Standard library first: the tool reads the data you point it at and sends nothing anywhere.

Where it fits

Use it when the output has to hold up to parsing or review, not when the voice is the point. Every rule can produce a false positive, so treat the findings as candidates for a rewrite.
