What it is

Standard-library Python CLI for ElevenMusic Muse text review: prompt, lyric, critique and prose frames, persistent conversations and offline tests. Unofficial private-API client; authenticated account required.

Судья ElevenMusic Muse как CLI — бесплатный эксперт по звуковым капшенам и текстам. Stdlib-only Python, без браузера в рантайме.

Install

git clone https://gitlab.com/ameobius-ai/elevenmusic-muse-plus.git

Python. Standard library first: the tool reads the data you point it at and sends nothing anywhere.

Where it fits

Use it when the output has to hold up to parsing or review, not when the voice is the point. Every rule can produce a false positive, so treat the findings as candidates for a rewrite.
